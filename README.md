# Ingeniería de Software: Sistema de Gestión Comercial

## 📋 Descripción
Este proyecto representa la fase de **Análisis y Planificación** de un sistema de gestión para empresas de servicios. Se aplicaron metodologías de ingeniería de software para transformar necesidades de negocio en especificaciones técnicas.

## 🛠️ Metodologías y Herramientas
* **Análisis Funcional:** Relevamiento de requerimientos con clientes reales.
* **Planificación de Proyectos:** Uso de diagramas **GANTT y PERT** para la gestión de tiempos y rutas críticas.
* **Modelado UML:** Diagramas de Casos de Uso, Clases y Flujo de Datos.
* **Análisis Estratégico:** Matriz FODA para la evaluación del entorno del proyecto.

## 🚀 Contribuciones Técnicas
* Definición de la lógica de stock automatizado y gestión de RRHH (comisiones/monotributistas).
* Diseño de la arquitectura de persistencia y reglas de negocio.
* Elaboración del plan de trabajo detallado para el ciclo de vida del desarrollo (SDLC).
